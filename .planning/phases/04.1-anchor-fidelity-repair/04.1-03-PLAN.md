<objective>
Widen the tracer's minimal anchor correction into the full F-10 fix: every drift shape the real proof run exhibited is corrected, safety-tier anchors are separately accounted for, pearls are handled honestly, the run reports what it moved, and the chunk prompt is tightened to reduce the drift at its source.

RESEARCH establishes it originates in the model's own completion — no StudyLoop code performs anchor arithmetic anywhere — so the tractable code-side fix is the deterministic post-merge correction layer D-01 item 2 locks in, backed by prompt tightening. RESEARCH's Pitfall 2 is the trap this plan is built to avoid: eight of the ten drifted units were already inside their own chunk's valid window, so a bounds check would have passed them while leaving a 160-second error on a DOSAGE card.

Output: the finished correction pass in `server/src/lib/anchorCorrect.ts` with a regression suite derived from the real drift table, correction telemetry in `runAnalysisJobV3`, and a tightened chunk prompt.
</objective>
